# React app

A Vite + React + TypeScript starter, styled with plain CSS.

- `src/main.tsx` mounts the app and imports the global styles.
- `src/App.tsx` is the page. Start editing here.
- `src/components/` holds reusable components, each with its own CSS file.
- `src/index.css` holds the design tokens (colors, radius, fonts) at the top.

Use plain CSS files imported from components. Tailwind is not set up.

```sh
npm install
npm run dev    # local development server
npm run build  # type-check and build to dist/
```
