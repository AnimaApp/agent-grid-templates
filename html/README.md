# HTML site

A static HTML, CSS and JavaScript site with no build step.

- `index.html` is the home page; `about.html` shows how a second page links in.
- `styles.css` holds every style, with the design tokens (colors, radius, fonts) at the top.
- `script.js` runs on every page.

Add a page by copying `about.html` and linking to it from the header of each page.
